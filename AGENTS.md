# AGEROLL PDF Editor

## Architecture

This is a TanStack Start and React application deployed on Netlify. `src/routes/index.tsx` contains the PDF editor interface and ephemeral session state. `src/routes/__root.tsx` owns metadata and the HTML shell. `src/styles.css` defines the responsive AGEROLL neutral-and-red design. Use the original logo at `public/assets/ageroll-logo.png`.

`src/lib/pdf-editor.ts` owns PDF parsing, original-font encoding, validation, sample generation, and export. PDF.js is dynamically imported only in the browser for rendering and text recognition; its worker is bundled through a Vite URL import. Matching CMaps, standard fonts, and WASM assets live in `public/pdf-assets/`. Refresh these assets when upgrading PDF.js.

## Editing rules

Preserve original document content. Never replace text by rasterizing a page, hiding it behind a white rectangle, or silently substituting a font. Only alter supported text-showing operands in existing content streams. Retain the original font and text state, and compensate the text advance so following content retains its position. Return exact source bytes when there are no changes.

Unsupported encodings, characters missing from embedded fonts, rotated text, inline-image streams, shared form objects, and ambiguous text matches must remain protected. Scanned pages have no editable text; OCR is not implemented. Do not imply universal PDF support. Keep the limitations visible in the help and error states.

All documents and edits live only in the current browser session. No persistence is required. If adding persistence later, use Netlify platform primitives and the relevant platform skills. Never introduce document uploads as an incidental implementation detail.

## Conventions

Use TypeScript with strict types and React hooks. Keep PDF manipulation outside presentation code. Import app modules with `@/`. Accessible controls need labels, visible focus, loading/disabled states, and errors. The help modal supports Escape, focus trapping, and focus restoration. Preserve mobile layouts and reduced-motion preferences.

`src/routeTree.gen.ts` is generated by the router plugin; do not edit it. Existing `src/components/ui/` contains reusable Radix primitives, and `src/components/error-pages.tsx` supplies route errors. `netlify.toml` defines deployment.

## Development

Install with `pnpm install`, develop with `pnpm dev`, and build with `pnpm build`. During hosted agent runs, obey the session's restrictions on local builds, tests, and dev servers; the platform validates deployment automatically. Review edited files before completing a change.
